Software
________

`Population genetics simulations <pop_lab/index.html>`_ are the simulations
written for our population genetics practices. Each one is a small interactive
application: set the parameters of a population, run it, and watch the allele
frequencies respond.

`Sequence comparison tools <edu/software/alignment/index.html>`_ teach basic
bioinformatic concepts.

Both run entirely in the browser: there is nothing to install, and no sequence
you type is sent anywhere.
